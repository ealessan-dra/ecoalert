📥 Instalação do XAMPP

Passo 1: Aguardar Download

O Windows está fazendo o download do XAMPP via winget. Aguarde a conclusão (148 MB).

Passo 2: Executar Instalador

Quando o download terminar, clique duas vezes no arquivo instalador.

Passo 3: Seguir Instalação

Caminho de instalação: C:\xampp (deixar padrão)
Componentes: Deixar todos selecionados (Apache, PHP, MySQL, phpMyAdmin)

Passo 4: Iniciar Serviços

Após instalação, abra o XAMPP Control Panel em C:\xampp\xampp-control.exe

  • Clique "Start" ao lado de Apache
  • Clique "Start" ao lado de MySQL
ℹ️ Dica: Se quiser que Apache e MySQL iniciem automaticamente, marque a caixa "Autostart" antes de clicar em "Start".

📂 Configurar Seu Projeto

Passo 1: Copiar Arquivos

Copie a pasta Eduarda Santiago para:

C:\xampp\htdocs\

Passo 2: Criar Banco de Dados

  1. Abra no navegador: http://localhost/phpmyadmin/
  2. Clique na aba "SQL"
  3. Copie o conteúdo do arquivo banco.sql (que está na pasta do projeto)
  4. Cole na caixa de SQL
  5. Clique "Executar"

🔧 Solução de Problemas

❌ Erro: "Não consegue conectar ao banco de dados"

Solução:
  1. Verifique se MySQL está rodando no XAMPP Control Panel
  2. Verifique as credenciais em conexao.php
  3. Certifique-se de ter executado o banco.sql

❌ Erro: "Página não encontrada (404)"

Solução:
  1. Verifique se a pasta está em C:\xampp\htdocs\
  2. Verifique a URL: http://localhost/Eduarda%20Santiago/arquivo.php
  3. Reinicie Apache no XAMPP Control Panel

❌ Erro: "Porta 80 já em uso"

Solução:

Abra Power Shell como admin e execute:

netstat -ano | findstr :80

Feche o programa que está usando a porta (geralmente outro Apache ou IIS).
